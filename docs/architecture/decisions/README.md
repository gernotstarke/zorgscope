# Architecture Decision Records

Format: [MADR](https://adr.github.io/madr/) (short form). File name `ADR-NNNN-kebab-title.md`, status one of
`proposed | accepted | deprecated | superseded by ADR-x`. New ADRs get the next number; never renumber.

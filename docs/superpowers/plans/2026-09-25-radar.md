# Radar view Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fourth view, `GET /radar`, drawing every open item as a blip on a radar scope, reachable from the switch and selectable as landing view in the cogwheel.

**Architecture:** A pure builder in `internal/web/radar.go` turns the snapshot's items, the site specs and `now` into a `radarView` holding every coordinate and every line of text; `templates/radar.html` prints it as inline SVG; `app.css` carries all colour, motion and hover behaviour. No JavaScript, no new dependency.

**Tech Stack:** Go `html/template`, inline SVG, hand-written CSS (`light-dark()`, `:has`), `hash/crc32`.

**Spec:** `docs/superpowers/specs/2026-09-25-radar-design.md`

## Global Constraints

* CSP has no `'unsafe-inline'`: no `style=` attribute anywhere in the page, colours only through classes.
* Every software change bumps `internal/version/version.go` — this feature: `1.9.0`.
* QS‑2.3: `/radar` over `representativeItems()` ≤ 150 kB.
* Run `go test ./internal/...` while iterating; `make check` (vet, lint, race tests, coverage, markdownlint) must pass before the last commit.
* Colour is never the only signal.

### Task 1: The radar builder

**Files:**

* Create: `internal/web/radar.go`
* Test: `internal/web/radar_test.go`

**Interfaces:**

* Consumes: `siteSpecs(config.GitHub) []domain.SiteSpec` (sites.go), `domain.Item.Tier()`, `domain.NeedsNow`, `newTimeView`, `kindShort`.
* Produces:

  ```go
  func buildRadar(items []domain.Item, gh config.GitHub, now time.Time) radarView
  type radarView struct {
      headerView
      Sectors []radarSector
      Rings   []radarRing
      Blips   []radarBlip   // calm first, loud last (drawn on top)
      Total, PRs, Issues, Needs, Security, Dependency int
  }
  type radarSector struct{ Name, Hue string; EdgeA, EdgeB radarLine; Rim string; LabelX, LabelY float64; Anchor string }
  type radarRing   struct{ R, LabelY float64; Label string }
  type radarBlip   struct{ X, Y float64; PR bool; Mark string /* "security"|"dependency"|"needs"|"" */;
                           Hue, Bearing /* "bearing-N" */, Age /* "age-0".."age-3" */, URL, Label, Tag string;
                           Shape string /* SVG path d or "" for circle */; R float64; Card radarCard }
  type radarCard   struct{ Head string; Title []string; Reason, ReasonClass string; Facts []radarFact; Summary []string }
  ```
